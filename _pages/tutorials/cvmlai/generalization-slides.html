01 / The failure mode

A low training loss can lie.

A model can memorize the examples it has seen and still fail on new ones. Watch both curves: validation loss is the signal that tells us when memorization starts to win.

03 / One objective, two goals

Regularize the function, not the score.

05 / Evaluation discipline

The test set is a one-shot exam.

Use validation results to choose settings. Touch the test set once, after decisions are final.

TRAIN

Fit parameters.

VALIDATE

Choose the recipe.

TEST

Report once.

Why the boundary matters

If test results influence model selection, the test set is no longer unseen. The reported score will be optimistic, even if no gradient ever touched those examples.
